# 移动端任务提醒方案

让一线同事能在手机上及时看到当日待办，并在应用内完成处理。这里的提醒仅面向已经分配负责人的任务。

## 提醒规则

任务到期前 30 分钟发送一次提醒。任务未完成时，系统在到期后再提醒一次。

用户关闭通知权限后，应用仍在待办列表标记临近到期的任务。用户处理任务后，当天不再收到该任务的提醒。

| 场景 | 处理方式 |
| --- | --- |
| 负责人变更 | 后续提醒只发给新负责人 |
| 任务已结束 | 停止发送提醒 |
| 通知发送失败 | 保留任务列表中的状态 |
