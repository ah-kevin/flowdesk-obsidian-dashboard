# FlowDesk 文档评审方案

让同事能在浏览器里评审 Obsidian 的方案和文档。评审提交后，反馈保存在作者本机，作者或 Agent 可以对照送审版本和当前原文继续修改。

## 一、发起评审

作者选择一份或多份方案。送审台自动列出直接引用的文档和附件，作者可以调整勾选。确认送审时，系统保存本轮材料的快照，并为评审人生成邀请链接。

| 作者操作 | 系统反馈 |
| --- | --- |
| 选择一份方案 | 列出关联资料及无法纳入的引用 |
| 调整关联资料 | 更新最终纳入的文档和附件数量 |
| 创建评审 | 固定本轮版本，显示邀请链接和打开评审页的入口 |

## 二、阅读与批注

评审人可以从目录打开关联文档，或者在正文里点击引用，直接跳到指定章节。返回上一份文档时回到原阅读位置。

划选文字或打开段落菜单，可以评论、高亮或建议改文。每条意见关联送审版本与正文位置，评论和改文可标为必改。草稿保存在当前浏览器，右侧可切换当前文档与全部反馈。

## 三、提交结论

评审人可以选择通过、需修改或仅反馈，并补充总体说明。提交会一次保存本轮所有草稿反馈及其结论。重复提交相同内容时返回原回执，内容冲突时保留草稿并允许另发一份评审。

## 四、作者接收与复审

送审台显示评审人、结论、原文引用、建议改文和必改标记。Agent 可以按原文路径读取意见及对应的冻结版本。作者根据意见更新原稿后，再发新版供复审。

## 五、本机验收

1. 创建一轮评审，用邀请打开评审页。
2. 任选一段文字评论，标为必改，再提交需修改。
3. 在作者端核对结论、评论和来源，验证 Agent 也能读到同一结果。
4. 更新方案后另发一轮，核对两个版本各自的结果。
